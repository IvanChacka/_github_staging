# RQvol

基于米筐 RQData 的期权 IV 分钟级变化监控。

## 功能

- 每分钟扫描活跃期权合约 IV 变化
- IV 上升超过 **2%** 或下降超过 **3%** 时触发预警
- 数据源：RQData (1分钟频率 Greeks)
- 覆盖标的：50ETF / 300ETF / 500ETF / 科创50ETF / 沪铜 / 沪金 / 螺纹钢 / 原油 / 中证1000期货

## 文件说明

- `rq_option_scanner.py` — 主扫描脚本
- `rq_option_data.json` — 扫描结果输出（自动生成）

## 使用方法

```bash
# 单次运行
python rq_option_scanner.py

# 持续监控（取消 run_loop() 注释）
```

## 输出格式

```
┌─ RQData 期权 IV 分钟变化 ─────────────────────┐
│ IV 最大上升 (≥2.0%)                            │
├──────────────────────────────────────────────┤
│ xxx  50ETF 13.4%→15.1% ↑1.7% │
│ ...
├──────────────────────────────────────────────┤
│ IV 最大下降 (≥3.0%)                            │
├──────────────────────────────────────────────┤
│ yyy  500ETF 25.8%→23.6% ↓8.5% │
└──────────────────────────────────────────────┘
```
